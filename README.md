# 🍓 ICHIGOMusic

**融合精致设计与极致声画体验的网易云音乐第三方桌面客户端**

*全屏沉浸式动态歌词 · 灵动悬浮桌面歌词 · 音频频谱可视化 · 双界面布局架构 · 局域/远程多人实时一起听 · 智能混洗心动模式*

---

## 核心特性

- **双布局架构**：经典侧边导航与现代流线毛玻璃卡片布局自由切换。
- **编辑感排版**：Newsreader 衬线标题 + Instrument Sans 界面字体，默认「暖纸」主题与自托管字体，离线启动也保持一致排版。
- **命令面板**：`Ctrl / Cmd + K` 快速搜索当前队列并执行播放、收藏、歌词、主题与页面跳转。
- **全景沉浸模式**：提供 10 款各具特色的全屏动效舞台（常规逐字、PV 动效、气泡、云阶、空间画布、黑胶、胶片、雾笺、绘光与町景模式）。
- **悬浮桌面歌词**：三行滚动排版、主歌词逐字动画、翻译歌词联动、文字辉光特效与鼠标穿透锁定。
- **智能心动模式**：基于红心曲库真随机混洗，并以 2:1 黄金比例动态穿插智能推荐好歌。
- **多人实时一起听**：生成专属房间链接，支持毫秒级播放进度同步、聊天互动与剪贴板极速识别。
- **多级解灰与全网音源**：内置 UNM 智能解灰机制与全网音源智能匹配，保障曲库完整播放体验。
- **高保真音频与可视化**：支持多档音质切换、多款动态频谱渲染，以及官方听歌时长与播放记录实时同步。

## 界面与功能展示

### 双布局界面设计

ICHIGOMusic 提供两套精心打磨的界面交互形态，可在设置中随时无缝切换。

#### 经典布局 (Classic Layout)
侧边导航清晰明确，歌单分类与推荐流一目了然，传承经典桌面音乐播放器的直觉操作。

#### 现代布局 (Modern Layout)
全景毛玻璃质感、灵动圆角浮动底栏与极简流线排版，带来更加轻盈通透的视觉体验。

![现代布局](./picture/现代布局.png)

### 全屏沉浸歌词系统

点击播放栏封面或全屏按钮即可进入沉浸模式。系统内置 10 款精心调校的沉浸视觉风格，支持专辑主色提取、动态光影模糊、多种视觉粒子及丰富的排版动画：

#### 1. 常规逐字模式
经典优雅的逐字平滑过渡，配合基于专辑封面主色调生成的呼吸光影与柔和渐变。

![沉浸模式 1 - 常规逐字](./picture/沉浸模式1.png)

#### 2. PV 动效模式
结合艺术字排版、动态镜头拉伸、节奏震颤与背景氛围渲染，呈现 MV 级的视听沉浸感。

![沉浸模式 2 - PV 模式](./picture/沉浸模式2.png)

#### 3. 气泡模式
将当前演唱歌词包裹于半透明轻盈气泡中，层次分明，带来生动有趣的视觉律动。

![沉浸模式 3 - 气泡模式](./picture/沉浸模式3.png)

#### 4. 云阶模式
立体的云阶层级透视与景深动效，歌词逐级上下滚动如行云流水般平顺。

![沉浸模式 4 - 云阶模式](./picture/沉浸模式4.png)

#### 5. 空间画布模式
广阔深邃的画布空间感，当前句与背景层次分明，营造沉浸专注的听歌体验。

![沉浸模式 5 - 空间画布](./picture/沉浸模式5.png)

#### 6. 黑胶模式
经典的黑胶唱片旋转质感与唱针交互，复古质感与现代动态歌词完美融合。

![沉浸模式 6 - 黑胶模式](./picture/沉浸模式6.png)

#### 7. 胶片模式
电影胶片质感的画幅风格与独特的复古颗粒光影，为音乐赋予浓郁的故事感。

![沉浸模式 7 - 胶片模式](./picture/沉浸模式7.png)

#### 8. 雾笺模式
雨夜车窗起雾，歌词按唱点一笔一笔写在雾气上，笔画走过处水珠顺着玻璃淌下；末句唱完会在玻璃上写下歌名与歌手。

#### 9. 绘光模式
体积光束与烟雾随低频能量呼吸，歌词逐字被光束点亮，配合线稿与暗场留白。

#### 10. 町景模式
日本小镇微缩街景，三层视差街景与缓慢运镜，歌词写在招牌与 LED 大屏上，可切换便利店 / 加油站 / 街角与昼雨氛围。

#### 沉浸参数深度调节
支持自由调节字号、行距、对齐方式、模糊强度、粒子特效及背景运镜速度。

![沉浸设置](./picture/沉浸设置1.png)

### 个性化定制与本地缓存

![设置界面](./picture/设置界面.png)

- **主题配色**：支持暗色/亮色模式智能跟随系统，内置多款定制主题色调。

## 快速上手

### 下载安装
前往 [Releases](https://github.com/sa1to-asuka/ICHIGOMUSIC/releases) 页面下载最新的 Windows 安装包（如 `ICHIGOMusic Setup 3.4.0.exe`），双击运行即可完成安装。

### 本地构建与运行

#### 环境要求
- Node.js (v18 或更高版本)
- npm / pnpm

#### 1. 克隆仓库并安装依赖
```bash
git clone https://github.com/sa1to-asuka/ICHIGOMUSIC.git
cd ICHIGOMUSIC
npm install
```

#### 2. 启动开发环境
```bash
# 启动前端服务
npm run dev

# 启动 Electron 主窗口
npm run electron
```

#### 3. 构建发布包
```bash
npm run electron:build
```
打包输出的可执行文件将生成于 `release/` 目录下。
